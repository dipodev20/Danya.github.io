# Danya Portfolio 2026

Static portfolio rebuilt as a small folder-based site.

## Structure
- `index.html` — complete responsive site
- `assets/character/` — supplied character illustrations
- `assets/projects/` — project logos, covers and screenshots

## Notes
- Phone number was removed from the public site.
- English/Russian switching is built into the page.
- No analytics, cookies, login system or third-party JavaScript libraries are included.
- Project descriptions are intentionally concise and based on the supplied portfolio materials/current site information.
